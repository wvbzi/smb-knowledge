# MoKnowledge Builder Application

Next.js 15 application for the MoKnowledge SMB Knowledge Builder.

For comprehensive documentation, architecture, scraping details, prompt engineering examples, and the Supabase database schema, please see the [Root README](../README.md).

## Local Development

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build
```
